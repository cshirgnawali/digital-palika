# 🏛️ Digital Palika

**Digital Palika** is a web-based **Smart Municipality Management & Analytics Dashboard** developed as a **BCA 6th Semester Project (PRJ 351)** using **Flask** and **MySQL**.

---

## ✨ Features

* 🔐 User authentication (Admin, Staff, Mayor, Citizen)
* 📢 Citizen complaint submission and tracking
* 🏗️ Project management system
* 💰 Budget management and analytics
* 🗺️ Ward and department management
* 📊 Dashboard reports and statistics
* 📱 Responsive Bootstrap-based UI

---

## 🛠️ Technology Stack

| Component       | Technology                       |
| --------------- | -------------------------------- |
| Backend         | Flask (Python)                   |
| Database        | MySQL                            |

## 🚀 Installation

### 1. Clone the repository

```bash
git clone https://github.com/cshirgnawali/digital-palika.git
cd digital-palika
```

### 2. Create virtual environment

```bash
python -m venv venv
```

### 3. Activate virtual environment

**Windows:**

```powershell
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure database

Create a `.env` file:

```ini
SECRET_KEY=digitalpalika123
MYSQL_HOST=localhost
MYSQL_USER=root
MYSQL_PASSWORD=your_password
MYSQL_DB=digital_palika
```

### 6. Run the application

```bash
python app.py
```

Open in browser:

```
http://127.0.0.1:5000
```
